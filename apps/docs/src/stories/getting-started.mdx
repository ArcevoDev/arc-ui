# Getting Started

Welcome to **facet**: the domain-customizable, auth-first component system for the Arcevo ecosystem.

facet provides a complete suite of React components, authentication primitives, design tokens, and app shells that work together seamlessly. Built on Radix UI and styled with Tailwind CSS, it ships with domain presets for fintech, healthcare, education, and enterprise.

## Quick Start

```bash
pnpm add @arcevo/facet-components @arcevo/facet-tokens
```

Import the design tokens and use any component:

```tsx
import "@arcevo/facet-tokens/tokens.css";
import { Button, Card } from "@arcevo/facet-components";

function App() {
  return (
    <Card>
      <Button variant="primary">Get Started</Button>
    </Card>
  );
}
```

## Package Architecture

| Package | Description |
|---|---|
| `@arcevo/facet-tokens` | Design tokens: colors, typography, spacing, sub-brand support |
| `@arcevo/facet-components` | 35+ styled UI components + theme system: Button, Dialog, Select, Table, Command, Navbar, and more |
| `@arcevo/facet-sdk` | API client for arc-id: auth, passkeys, tenant, billing, webhooks |
| `@arcevo/facet-auth` | Auth components: ArcProvider, SignIn, SignUp, UserButton, Guard, MfaDialog, standalone forms |
| `@arcevo/facet-layout` | App shells: ConsoleLayout, AuthLayout (auth pages), LandingLayout, Sidebar, Topbar, PageHeader, 5 domain presets |

## Starting with Auth

```tsx
import { ArcProvider, SignIn, Guard } from "@arcevo/facet-auth";
import { ArcIdClient } from "@arcevo/facet-sdk";
import { fintechPreset } from "@arcevo/facet-auth";

const client = new ArcIdClient({ baseUrl: "https://auth.arcevo.dev/api/v1" });

function App() {
  return (
    <ArcProvider client={client}>
      <Guard fallback={<SignIn config={fintechPreset} />}>
        <Dashboard />
      </Guard>
    </ArcProvider>
  );
}
```
