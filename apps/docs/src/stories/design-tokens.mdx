## Typography

| Token | Value | Usage |
|---|---|---|
| `--font-heading` | Montserrat | Headings, titles |
| `--font-body` | Inter | Body text, UI labels |
| `--font-mono` | JetBrains Mono | Code, monospace |
| `--font-technical` | Rajdhani | Technical UI, data displays |

## Spacing & Radius

| Token | Value |
|---|---|
| `--radius` | `0.5rem` (base) |
| `--radius-sm` | `0.3rem` |
| `--radius-lg` | `0.5rem` |
| `--radius-xl` | `0.7rem` |

## Sub-Brand System

Set `--sub-brand-accent` and `--sub-brand-accent-foreground` at runtime to customize the accent color per brand:

```css
.my-brand {
  --sub-brand-accent: oklch(0.6 0.18 160);
  --sub-brand-accent-foreground: oklch(0.99 0 0);
}
```
