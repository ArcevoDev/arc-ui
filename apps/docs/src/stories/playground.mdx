## Get Started

```bash
pnpm add @arcevo/facet-components @arcevo/facet-tokens @arcevo/facet-auth @arcevo/facet-layout
```

```tsx
import "@arcevo/facet-tokens/tokens.css";
import { Button, Card } from "@arcevo/facet-components";

function App() {
  return <Button variant="default">Hello facet</Button>;
}
```
