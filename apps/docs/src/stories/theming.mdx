# Theming

facet is **dark-first**: the default theme uses dark backgrounds with light text. A light theme can be enabled by toggling a `data-theme` attribute.

## How It Works

All design tokens are defined in `:root`. When `data-theme="light"` is set on the `<html>` element, light values override the defaults:

```css
[data-theme="light"] {
  --background: oklch(0.98 0.01 240);
  --foreground: oklch(0.12 0.02 240);
  /* ... more overrides */
}
```

## ThemeProvider

The `@arcevo/facet-components` package ships a complete theme system: `ThemeProvider`, `ThemeToggle`, and `useTheme`. It supports light/dark/system, persists to `localStorage`, follows the OS preference, and lets consumers override any token per brand.

```tsx
import {
  ThemeProvider,
  ThemeToggle,
  useTheme,
} from "@arcevo/facet-components";

function App() {
  return (
    <ThemeProvider defaultTheme="system">
      <Nav />
      <Page />
    </ThemeProvider>
  );
}

// Anywhere inside the provider:
function Nav() {
  const { theme, resolvedTheme, toggleTheme } = useTheme();
  return <ThemeToggle />;
}
```

## Customizing Tokens Per Brand

Pass `overrideVars` to remap any design-token CSS variable for a brand or domain: useful for fintech, healthcare, and education consumers:

```tsx
<ThemeProvider
  defaultTheme="dark"
  overrideVars={{
    "--primary": "oklch(0.55 0.2 162)", // brand green
    "--sub-brand-accent": "oklch(0.6 0.15 250)",
  }}
>
  <App />
</ThemeProvider>
```

## System Preference

Use `theme="system"` to follow the OS preference. The provider resolves it to light/dark via `prefers-color-scheme` and re-applies on OS changes. The resolved value is exposed as `resolvedTheme`.

## Domain Presets

facet ships with auth domain presets. Each preset configures MFA requirements, passkey support, session TTL, and more:

| Preset | MFA | Passkey | Session TTL | Use Case |
|---|---|---|---|---|
| `fintechPreset` | Required | Yes | 15 min | Trading, banking |
| `medPreset` | Required | No | 30 min | HIPAA-compliant |
| `eduPreset` | Optional | Yes | 12 hr | Student portals |
| `enterprisePreset` | Required | Yes | 8 hr | SSO + MFA |
| `defaultPreset` | Optional | Yes | 8 hr | General |
