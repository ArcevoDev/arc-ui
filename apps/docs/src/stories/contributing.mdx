# Contributing

## Code Conventions

- **Named exports only** — no default exports anywhere
- **CN utility** — always use `cn()` from `@arc-ui/components` for className merging
- **CVA variants** — use `class-variance-authority` for components with variant props
- **Radix adapters** — follow the existing pattern: direct alias for stateless wrappers, `forwardRef` for styled ones
- **displayName** — always set `displayName` on wrappers, matching the Radix primitive

## Adding a Component

1. Create the file in `packages/components/src/ui/{name}.tsx`
2. Export from `packages/components/src/index.ts`
3. Add a `.stories.tsx` file in `apps/docs/src/stories/`
4. Run `pnpm typecheck` and `pnpm build`

## File Structure

```
packages/
  tokens/src/     — Design tokens (TypeScript + CSS)
  sdk/src/        — API client modules
  components/src/ — UI components (ui/ subfolder)
  auth/src/       — Auth components (provider, sign-in, guard, etc.)
apps/
  docs/           — Storybook documentation site
  landing/        — Landing page
```

## Before Submitting

- `pnpm typecheck` — zero errors
- `pnpm build` — all packages build clean
- Stories render in Storybook with controls and dark/light toggle
